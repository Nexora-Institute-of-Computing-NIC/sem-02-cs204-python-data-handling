# CS204 — Python for Data Handling — PLAN

**Semester:** 2 · **Credits:** 3 · **Level:** Beginner-Intermediate
**Theory:** 30 hrs · **Lab:** 30 hrs · **Tools:** Python 3, Jupyter, pandas, NumPy, matplotlib

## Syllabus

### Unit 1 — Python Fundamentals (9 lectures)
1. Why Python — readability, batteries included, ecosystem
2. Installation and virtual environments
3. Variables, dynamic typing, and the REPL
4. Numbers, strings, and string formatting (f-strings)
5. Lists, tuples, and indexing
6. Dictionaries and sets
7. Control flow — if, for, while, comprehensions
8. Functions — arguments, defaults, kwargs
9. Modules, packages, and imports

### Unit 2 — File Handling and Text Processing (9 lectures)
1. Reading and writing text files
2. Working with paths and directories (`pathlib`)
3. CSV files — reading and writing
4. JSON — parse and generate
5. Regular expressions — search, match, sub
6. Log file parsing
7. Text encoding — UTF-8, errors, pitfalls
8. Working with large files — line-by-line processing
9. Exception handling in file operations

### Unit 3 — NumPy and Numerical Data (9 lectures)
1. Why NumPy — speed and memory
2. Arrays vs lists
3. Creating arrays — zeros, ones, arange, linspace
4. Indexing and slicing — 1D and 2D
5. Vectorised operations and broadcasting
6. Aggregations — sum, mean, std, min, max
7. Reshaping, stacking, splitting
8. Random number generation and seeds
9. Performance — vectorise instead of loop

### Unit 4 — pandas and Tabular Data (9 lectures)
1. Why pandas — labelled data
2. Series and DataFrame
3. Reading CSV, Excel, JSON into DataFrames
4. Selecting, filtering, sorting
5. Missing data — detect, fill, drop
6. Grouping and aggregation — `groupby`
7. Merging and joining DataFrames
8. Pivot tables and crosstabs
9. Exporting — CSV, Excel, JSON

### Unit 5 — Visualisation and Reporting (9 lectures)
1. Why visualise — insight and communication
2. matplotlib basics — plot, scatter, bar, hist
3. Customising plots — labels, legends, colours
4. Subplots and figures
5. seaborn for statistical plots
6. Time series plotting
7. Interactive visualisation (plotly) — overview
8. Exporting charts and building a report
9. Clean code and reproducibility — notebooks vs scripts

## Practical Labs (18)

1. Set up Python, venv, and Jupyter
2. Solve 10 small problems with lists and dicts
3. Text file reader — word and line counts
4. CSV loader with error handling
5. JSON config reader
6. Regex — extract emails and phone numbers from text
7. Log analyser — count errors by level
8. NumPy array warm-up — 10 operations
9. NumPy broadcasting — normalise a matrix
10. NumPy — vectorised vs loop performance comparison
11. pandas — load and inspect a dataset
12. pandas — clean missing data
13. pandas — groupby and summary statistics
14. pandas — merge two datasets
15. pandas — pivot table from a sales dataset
16. matplotlib — four plot types on one dataset
17. seaborn — correlation heatmap
18. Final notebook — end-to-end mini analysis report

## Assignments

1. Python basics — 15 small exercises
2. Text processing — build a log summariser
3. NumPy — vectorised numerical exercise
4. pandas — clean and analyse a real CSV
5. Final notebook — a reproducible data report
